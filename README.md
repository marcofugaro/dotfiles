# dotfiles

Most commands taken from https://github.com/mathiasbynens/dotfiles

## Usage

1. Download the repo as a zip from https://github.com/marcofugaro/dotfiles/archive/refs/heads/master.zip and unzip it.
2. In the unzipped folder, run `./setup.sh`.
3. Then run `./setup-macbook.sh` on the MacBook, or `./setup-mac-mini.sh` on the Mac mini.
4. Optionally, for the status lamp on the Mac mini, run `./setup-mac-mini-status-lamp.sh`.
